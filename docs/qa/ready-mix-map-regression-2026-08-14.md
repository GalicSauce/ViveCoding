## 결함 재검증

### QA-01 · 보통 · 지도 마커 접근 가능한 이름 — 해결

- 관련 파일: `js/app.js`의 `renderReadyMixMap()`
- 재현:
  1. 지도 탭에서 업체 마커를 생성한다.
  2. 접근성 트리에서 각 Leaflet 마커의 이름을 확인한다.
- 기대 결과: 각 마커가 해당 업체명으로 식별된다.
- 수정 결과: 업체명에서 제어문자를 제거해 `accessibleName`을 만들고, `L.marker`에 업체별 `title`, `${accessibleName} 위치` 형식의 `alt`, `keyboard: true`를 전달한다.
- 재검증 결과: **통과**. 빈 업체명 fallback까지 포함되어 마커가 의미 있는 이름과 키보드 접근성을 갖는다.

## 잔여 환경 제한

390px과 320px 뷰포트는 실행 환경 제약으로 실화면 측정을 수행하지 못했다. 해당 구간의 760px·440px·340px 미디어쿼리, `min-width: 0`, 단일 열 지도 레이아웃과 입력·버튼 폭 제한은 정적으로 확인했다. 현재 확인 범위 내 출시 차단 결함은 없다.
