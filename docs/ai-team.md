# AI 개발팀 사용 가이드

이 프로젝트에는 네 명의 프로젝트 전용 Codex 서브에이전트가 등록되어 있다. 새 Codex 작업을 프로젝트 루트에서 시작하면 `AGENTS.md`와 `.codex/config.toml`이 자동으로 적용된다.

## 담당자

| 담당자 | Codex 에이전트 이름 | 담당 영역 |
|---|---|---|
| HTML 담당 이씨 | `html_lee` | `index.html`, 시맨틱 HTML, 폼, 표, 접근성 |
| CSS 담당 강씨 | `css_kang` | `css/styles.css`, 레이아웃, 반응형, 시각 접근성 |
| JS 담당 서씨 | `js_seo` | `js/app.js`, 상태, 검증, 계산, DOM 동작 |
| QA 엔지니어 김씨 | `qa_kim` | 기능·회귀·접근성·반응형·계산 검증 |

## 가장 쉬운 사용법

평소처럼 메인 에이전트에게 자연어로 요청하면 된다. 메인 에이전트가 파일과 업무에 맞는 담당자를 선택한다.

```text
사업장 설정 화면을 더 사용하기 쉽게 개선해줘. 담당 개발자가 수정하고 김씨가 검증해줘.
```

담당자를 직접 지정할 수도 있다.

```text
이씨에게 활동자료 표의 HTML 접근성을 개선해줘.
강씨에게 390px 모바일 레이아웃을 수정해줘.
서씨에게 다년도 산정 로직을 구현해줘.
김씨에게 예시 데이터 계산과 모바일 화면을 회귀 테스트해달라고 해줘.
```

여러 담당자를 함께 부르는 예시:

```text
이씨와 강씨가 입력 화면을 개선하고, 서씨가 필요한 동작을 연결한 뒤, 김씨가 전체 흐름을 검증해줘.
```

## 정체성 확인

다음과 같이 질문하면 각 담당은 고정된 문장으로 답한다.

```text
이씨, 이름과 역할이 뭐야?
```

예상 답변:

```text
나는 HTML 담당 이씨야.
```

## 적용 시점

설정을 만든 현재 작업에서는 팀 구성이 이미 적용되어 있다. 이후 새 작업이나 Codex 재시작에서도 프로젝트 루트 `C:\VibeCoding\study`에서 시작하면 자동으로 적용된다. 설정이 보이지 않으면 Codex에서 새 작업을 열어 다시 시작한다.
